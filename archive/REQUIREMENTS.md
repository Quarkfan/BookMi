# BookRoom - 原始需求记录

> 记录日期：2026-05-28
> 说明：本文档忠实记录用户原始想法，不做扩展和结构化，仅作为需求采集存档。

---

## 需求列表（按沟通顺序）

1. 当前目录是用于开发一个苹果 app 的
2. app 的目标是书房管理，支持我扫码藏书
3. 支持导入现有图书
4. 支持获取图书图片
5. 支持搜索图书，支持全局字段搜索，支持指定字段筛选
6. 支持给图书打自定义标签
7. 支持设置书柜概念，记录存储位置
8. 支持批量删除图书，批量移动书柜中的图书到另一个书柜，批量添加标签
9. 支持记录阅读进度
10. 支持批量标记读完
11. 扫码的录入的时候支持我选择默认书柜、默认标签，然后录入的时候自动加上（扫码扫的是图书的一维码）
12. 支持网络搜索书籍藏书
13. 支持手动录入藏书
14. 支持一定的分析能力：
    - 全部藏书数量
    - 年度藏书
    - 按照书柜统计书籍数量
15. 支持借出管理
16. 支持 csv 的书籍导入
17. 支持匹配图书封面
18. 支持导出图书信息，包括 csv 的图书信息，以及对应的压缩包的封面信息
19. 具体导出的字段可以选择
20. 支持藏书分析，包括作者、出版社、购买渠道、热门标签等维度
21. 支持配置购买渠道
22. 支持阅读统计，支持在读已读等维度统计
23. 支持拍照录入出版信息
24. 支持显示设置，包括列表平铺等模式
25. 为了本地搜索图书，要支持模糊搜索，要建立拼音索引，对应的要支持我重建索引
26. 支持我选择按照拼音排序、添加时间、编辑时间进行排序或者首字母排序
27. 支持我设置一个启动密码保证安全
28. 支持我将数据备份同步到 icloud

---

## 功能速查表

| 模块   | 功能                                                |
| ---- | ------------------------------------------------- |
| 图书录入 | 扫码藏书（一维码/ISBN）、网络搜索藏书、手动录入、拍照录入出版信息、导入现有图书、CSV 导入 |
| 扫码默认 | 可设置默认书柜、默认标签，录入时自动添加                              |
| 信息管理 | 封面匹配、自定义标签、书柜管理（记录位置）                             |
| 批量操作 | 批量删除、批量移动书柜、批量添加标签、批量标记读完                         |
| 搜索筛选 | 全局字段搜索、指定字段筛选、模糊搜索（拼音）、拼音索引、重建索引                  |
| 排序   | 按拼音排序、按添加时间、按编辑时间、按首字母排序                          |
| 阅读管理 | 记录阅读进度、标记在读/已读、批量标记读完                             |
| 借出管理 | 记录借出信息                                            |
| 统计分析 | 全部藏书数量、年度藏书、按书柜统计、按作者统计、按出版社统计、按购买渠道统计、热门标签统计     |
| 阅读统计 | 在读/已读等维度统计                                        |
| 购买渠道 | 配置购买渠道、按渠道分析                                      |
| 导出   | CSV 导出、封面压缩包、可选导出字段                               |
| 显示设置 | 列表模式、平铺模式、模式切换                                    |
| 安全   | 启动密码、iCloud 备份同步                                  |
